# Smash Padel Club — desktop downloads

Mac and Windows builds of Smash Padel Club. Grab the newest one from [Releases](../../releases/latest).

- **Windows:** unzip, then run `SmashPadel.exe` inside the `Smash Padel Club` folder.
- **Mac:** unzip, then open `Smash Padel Club`.

This repository only holds release files; there is no source code here.
